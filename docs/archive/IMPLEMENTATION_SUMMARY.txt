LOGGING PATTERN
---------------
Each service now creates:
  - {service-name-lowercase}-{PID}-stdout.log (standard output)
  - {service-name-lowercase}-{PID}-stderr.log (standard error)

Examples:
  producer-12345-stdout.log
  producer-12345-stderr.log
  digitalchannels-12346-stdout.log
  digitalchannels-12346-stderr.log
  insurance-12347-stdout.log
  insurance-12347-stderr.log

FILE CREATION FLOW
------------------
1. Create temporary log file: {service}-temp-{random}.{stdout|stderr}.log
2. Start process with redirection to temp file
3. Get process PID from Start-Process return value
4. Rename temp file to final name: {service}-{PID}-{stdout|stderr}.log
5. Display log file paths in console output

This ensures:
  ✓ Atomic naming (files have correct names after startup)
  ✓ No PID collisions (even with concurrent runs)
  ✓ Safe recovery (temp files have descriptive names if interrupted)
